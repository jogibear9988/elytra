# ADR 0013: URL globals on unmodified LibURL

Status: implemented subset, verified on macOS ARM64 against Node v24.15.0.

Reuse Ladybird LibURL for WHATWG parsing, serialization, origin computation,
component mutation and form-urlencoding. The runtime already links LibURL for
module identities; no LibWeb/UI dependency or engine modification is needed.
Keep a small C++ adapter in mite/runtime/URL.cpp. Form encoding/decoding uses the
upstream LibURL FFI, retaining borrowed inputs only for the synchronous native
call and copying callback output before the Rust call returns. These API
assumptions are checked on upstream updates by compilation and behavioral tests.

Implement the URL/URLSearchParams JavaScript surfaces in our builtin layer.
Private WeakMap records provide branding and GC ownership, with the URL and its
search-params object keeping their live association. Mutations update the same
params object; iterators observe the current list even after replacements.
UTF-16 scalar conversion, record/iterable inputs, duplicate keys, optional-value
has/delete, stable sorting, callback receivers and iterable behavior are covered.
URL statics canParse/parse, component setters, origin/toJSON and constructor/error
shapes are included. CJS/ESM builtin exports share the constructors installed as
globals before application code runs. Generic invalid URL receiver errors differ
from URLSearchParams ERR_INVALID_THIS, matching the executable reference.

The differential suite compares 1,013 calls/scenarios across URL/base parsing,
opaque/file/blob/custom URLs, IDNA/IPv4/IPv6, credentials and encoding, setters,
invalid inputs, search-params parsing/mutation/live iteration, iterator branding,
URL/search-params synchronization and global/builtin identity. It compares
values and error name/code/input/base, not stack traces or diagnostic wording.
This corpus is not the entire Web Platform Tests or Node URL test suite.

Node file-URL helpers, HTTP options, domain helpers, legacy url.parse/format/
resolve/Url and Blob object URLs remain absent at this step. Native Windows/Linux
execution remains unverified. URLPattern is not installed. No claim of complete
Node url or browser URL API compatibility is made. Ladybird remains unmodified.

References: [WHATWG URL](https://url.spec.whatwg.org/),
[Node URL API](https://nodejs.org/docs/latest-v24.x/api/url.html).
